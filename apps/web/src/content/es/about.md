## Qué es

AI Robots.txt Generator (airobotstxtgenerator.com) incluye un generador, un verificador, un registro de rastreadores de IA con una página para cada uno, reglas de servidor y guías. Todo lo que puede ejecutarse en tu navegador se ejecuta allí —generación, análisis, prueba de archivos pegados— y funciona sin conexión una vez cargada la página. El único componente de servidor obtiene el robots.txt público de un sitio cuando pides una comprobación en vivo.

Forma parte de una pequeña red de herramientas gratuitas de un solo propósito del mismo autor, entre ellas ibangenerator.io y metasnitch.com. No hay cuentas ni muros de pago en las herramientas, y el único límite es un límite de frecuencia en las comprobaciones en vivo para evitar abusos.

## Cómo se mantiene el registro

Cada entrada revisada se comprueba con la documentación del propio operador y se fecha; la página indica cómo se comprobó. Una tarea automática semanal compara nuestra lista comunitaria con el proyecto de código abierto [ai.robots.txt](https://github.com/ai-robots-txt/ai.robots.txt) y abre una pull request con los cambios, que se revisan antes de publicarse. El analizador se prueba con todos los casos de prueba del analizador de robots.txt de código abierto de Google y con 46 archivos robots.txt reales cuyos resultados comparamos con el analizador compilado de Google. El código y los datos son abiertos: consulta [Licencias](page:licenses).

## Por qué nuestro propio robots.txt permite todos los bots de IA

Nuestro [robots.txt](/robots.txt) nombra a GPTBot, ClaudeBot, PerplexityBot, Google-Extended y a todos los demás agentes del registro, y los permite todos. Puede parecer raro en un sitio que ayuda a bloquear rastreadores de IA, pero se deriva del mismo principio: **decidir por finalidad**. Este sitio existe para responder preguntas; queremos que los asistentes de IA lo lean, lo citen y envíen gente aquí, y no nos importa que nuestras explicaciones acaben en los datos de entrenamiento de un modelo si eso mejora las respuestas. Un editor de periodismo de pago o de arte original decidirá, con razón, otra cosa. La herramienta está hecha para que cualquiera de las dos decisiones sea fácil y correcta.

También publicamos [/llms.txt](/llms.txt), [/llms-full.txt](/llms-full.txt), una versión en Markdown de cada página (añade `.md` a la dirección) y todo el registro como [/bots.json](/bots.json).
